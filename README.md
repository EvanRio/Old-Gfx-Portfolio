# 🎨 Portfolio GFX - Locyzz

Bienvenue sur le dépôt de mon ancien site vitrine ! Ce projet web avait pour but de présenter mon portfolio et mes compétences en tant que graphiste (GFX) pour différents types de plateformes (YouTube, Discord, Instagram, etc.).

## 👀 Aperçu du projet

Ce site web utilise un système de carrousels infinis (défilement automatique) pour exposer mes différentes créations de manière dynamique. Il est conçu pour être visuellement attractif avec des animations fluides et un thème sombre qui met en valeur les visuels.

### 🖼️ Catégories de créations présentées :
* **Bannières Discord**
* **Logos professionnels & gaming**
* **Miniatures YouTube**
* **Bannières YouTube**
* **Posts Instagram**

## 💻 Technologies utilisées

* **HTML5** : Structure de la page et intégration des grilles d'images.
* **CSS3** : Animations de défilement (`@keyframes`), effets de brillance (glow), typographie personnalisée (*Lilita One*, *Anton*) et design 100% responsive (adapté aux mobiles et PC).
* **JavaScript (Vanilla)** : Gestion simple des redirections vers d'autres catégories/produits via un menu déroulant.
